📊 Gerador de Backtest Pine Script (TradingView)

O código abaixo representa exatamente as regras de entrada e saída configuradas no robô (estratégia atual). Cole-o no editor de Pine Script do TradingView para rodar a simulação histórica.

📄 Código Pine Script v5

📋 Passo a Passo de Execução

  1. Acesse tradingview.com e abra o gráfico do par operado (ex: Gold / XAUUSD).
  2. Configure o mesmo tempo gráfico do robô (ex: 15 minutos).
  3. No rodapé da página, clique na aba "Editor do Pine" (Pine Editor).
  4. Apague todo o código existente lá e cole o código gerado acima.
  5. Clique no botão azul "Adicionar ao gráfico" (Add to chart).
  6. Vá para a aba ao lado "Testador de Estratégia" (Strategy Tester) para ver o resultado do backteste!
  7. Você pode clicar na engrenagem ⚙️ no gráfico para reconfigurar os parâmetros no TradingView de forma interativa.
